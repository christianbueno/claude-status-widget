# Contributing

Thanks for your interest in Claude Status Widget!

## Policy

This is a personal project and **pull requests are not accepted**. Code contributions will be closed without review.

## What you can do

- **Fork it** — clone the repo and build whatever you want on top of it. The MIT license gives you full freedom to modify, distribute, and use it however you like.
- **Report bugs** — open an issue if you find a problem. Bug reports with clear reproduction steps are appreciated.
- **Request features** — open an issue to suggest an idea. There's no guarantee it will be implemented, but feedback is welcome.

## Issues

When opening an issue, please include:

- A clear description of the problem or suggestion
- Steps to reproduce (for bugs)
- Your OS version and Node.js version
